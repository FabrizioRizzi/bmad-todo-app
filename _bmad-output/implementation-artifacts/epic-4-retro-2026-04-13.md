## What went well

- **100% story completion** with all 4 stories reaching done status and all review findings addressed (11 patched, 2 deferred as low-priority).
- **Opus 4.6 model quality:** Stories implemented with Claude Opus 4.6 (4.2, 4.3, 4.4) produced fewer structural issues than the baseline (4.1). Story 4.4 — the most complex (13-animation inventory, 51 tests) — came through review with zero findings. Deferred items only appeared in 4.1 (non-Opus).
- **Reusable patterns created:** `useReducedMotion` hook (shared across components, replacing inline `matchMedia`), `forwardRef` + `requestAnimationFrame` focus restore pattern (coordinates with FLIP animation), `createAnnouncement` versioning for repeat live-region announcements.
- **Animation system rigor:** All 13 animations mapped to tokens, 6 misalignments fixed (card enter direction, easing tokens, skeleton pulse opacity, toast timing, error banner height collapse), zero raw `ms` literals confirmed in TSX across 22 source files.
- **Previous retro follow-through:** Epic 3's keyboard smoke-test action item was directly fulfilled by Story 4.1. Targeted e2e regression practice continued — existing specs updated across 4.2 and 4.3 when labels changed.
- **Test coverage depth:** 92+ new tests including hook tests, token reference tests, CSS class tests, reduced-motion behavior, duration cap verification, raw literal scanning, and Playwright e2e at 3 viewports.

---

## What was challenging

- **E2e locator fragility:** Checkbox locators were updated in 3 of 4 stories (4.1, 4.2, 4.3) as accessible name patterns changed. Building `RegExp` from user text without escaping caused breakage with special characters (caught in 4.3 review). Root cause: no centralized page object for label construction.
- **Cross-story file overlap:** Every story touched `todo-card.tsx`, `app.tsx`, and `globals.css`. Story 4.2 ARIA work bled into the 4.3 diff (caught in review, accepted). Inherent to polish/accessibility epics where conceptual separation doesn't map to code separation.
- **Deferred tech debt from 4.1:** Post-delete focus restore uses `document.querySelector` on `li[data-todo-id]`, coupling App to list markup. Undo toast Escape handler in document capture phase may conflict with other overlays. Both low-priority but carrying forward.

---

## Learnings (carry forward)

1. **Model selection matters measurably:** Opus 4.6 correlated with zero structural deferrals and cleaner first passes. Standardize on Opus 4.6 for dev-story and code-review workflows.
2. **Accessibility epics cause inherent file overlap:** Accept that polish work crosses story boundaries at the code level. Mitigate via careful review, not rigid scope enforcement.
3. **Page objects solve locator churn:** Centralized label construction in `e2e/fixtures/todo-page.ts` (Epic 5, Story 5.3) will prevent the cascading locator updates seen in Epic 4.
4. **Animation contracts are valuable:** Documenting the 13-animation inventory with token mappings made alignment auditable and testable (51 tests in 4.4 alone).
5. **`useReducedMotion` as shared hook pattern:** Extracting media query listeners into hooks (instead of inline `matchMedia`) improves testability and consistency across components.
